Block 1 · Partial derivatives

A partial derivative freezes every input but one

For f(u, v), the partial ∂f/∂u is the week 1 derivative of u ↦ f(u, v) with v held fixed.

Geometrically: slice the surface along the u-direction and take the slope of the slice.

Example

f(u, v) = u² v + e^v
∂f/∂u = 2uv, ∂f/∂v = u² + e^v

What goes wrong

Forgetting that the frozen input is still in the formula. In ∂f/∂u = 2uv, the value of v matters: the slope along u differs from slice to slice.

Work the example on the board. Then the case's version, without numbers: the completion model's two partials share the factor sigmoid times one minus sigmoid, and differ only by their weight. Leave the computation to the lab.

Block 1 · In a model

In a logistic model every partial shares the factor σ(1 - σ)

r(u, v) = sigmoid(3*u + 2*v - 2.5)

dr/du = 3 * r * (1 - r)
dr/dv = 2 * r * (1 - r)

# at (u, v) = (0.45, 0.45): r = 0.438
# dr/du = 0.738, dr/dv = 0.492

The ratio is the weights'

dr/du ÷ dr/dv = 3 ÷ 2 at every point.

The size is the curve's

σ(1 - σ) is largest, 0.25, where r = 0.5, and near 0 when the model is sure. Sure models learn slowly: week 7.

This is a re-enrolment model invented for the slide, scaled so both inputs run from 0 to 1, not the completion model of the lab. The numbers come from labs/_tools/make_figures.py. The flat ends of the sigmoid come back when softmax saturates in week 7.

Block 2 · The gradient

The gradient turns week 1's line into a plane

Local linear approximation, n inputs

f(x + δ) ≈ f(x) + ∇f(x) · δ

∇f = (∂f/∂x₁, …, ∂f/∂xₙ): one number per input, stacked into a vector.

The dot product adds the effect of each input's change, as if each acted alone. Near x that is accurate.

Directional derivative

The rate of change along a unit vector u is ∇f · u. For the re-enrolment model at (0.45, 0.45): along u alone 0.738; along (0.6, 0.8) it is 0.837.

Compute 0.738 × 0.6 + 0.492 × 0.8 = 0.837 on the board. The dot product is from FND-MTH-101; here it is the whole of the first-order effect. Ask: which unit direction gives the largest value? Hold the answer for the next slide.

Block 2 · Direction of steepest increase

The gradient points uphill, across the level sets

r(u, v) = σ(3u + 2v - 2.5), a parallel example; labs/_tools/make_figures.py.

∇f · u = |∇f| cos θ: largest when u points along ∇f.

The largest rate is |∇f|: 0.887 at (0.45, 0.45).

Along a level set f does not change, so the gradient is perpendicular to it.

Descent. −∇f is the steepest way down: week 5.

The arrows are longest where contours are dense: the function changes fast there. The figure uses equal axes on purpose: with stretched axes the arrows stop looking perpendicular, a classic misreading of contour plots. The lab finds the best direction numerically over 360 angles and compares it with the gradient.

Block 3 · Several outputs

A Jacobian stacks one gradient per output

For F: ℝⁿ → ℝᵐ, the Jacobian J is m × n: row i is ∇Fᵢ, entry (i, j) is ∂Fᵢ/∂xⱼ.

Local linear map

F(x + δ) ≈ F(x) + J δ

A matrix times a vector, as in FND-MTH-101: J is the best linear map near x.

The district map

Five budgets in, five enrolment counts out. Each district depends only on its own budget, so every off-diagonal entry is 0: J is diagonal, with kᵢ / (sᵢ + xᵢ) on the diagonal.

Write the 2 by 2 Jacobian of (u v, u + v²) on the board: rows (v, u) and (1, 2v). Then the district map, whose diagonal shape is a modelling assumption: no spill-over between districts. The lab asks participants to say whether they believe it.

Block 3 · Checking a gradient

Check every coordinate with central differences and a relative error

def rel_err(g, g_num):
    return norm(g - g_num) / max(norm(g), norm(g_num))

# g_num[i] = (f(x + h e_i) - f(x - h e_i)) / (2h)
# h = 1e-6, one pair of evaluations per input
Relative errorRead it as
below 1e-7correct
1e-7 to 1e-4suspicious: a kink, or a large step
above 1e-2a wrong formula
Look per coordinate. One wrong entry among correct ones points at one formula.

The bands are rules of thumb for float64 and smooth functions with values of moderate size, not laws; a function near a kink (ReLU at 0) breaks them. The lab builds this checker and finds a planted mistake in last term's notes with it; do not say which component.
